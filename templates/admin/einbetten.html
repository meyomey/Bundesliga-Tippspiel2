🏆 Rangliste in die Website einbetten

Copy-Paste-Blöcke für die Vereins-Website — hell & dunkel, responsiv. Die Live-Variante holt sich das Podium direkt von hier und aktualisiert sich nach jedem Spieltag von selbst.

🎚️ Theme wählen (nur Live-Variante)

Der Schalter steckt in der iFrame-URL:

/embed/podium?theme=hellHell — passt zu hellen Webseiten
/embed/podiumDunkel (wie in der App)
/embed/podium?theme=autoFolgt dem System des Besuchers

✨ Variante A — Live-Podium (iFrame, empfohlen)

Immer aktuell (hier gezeigt in Hell). Die Höhe stellt sich automatisch ein — das Widget meldet sie dem iFrame (ab App-Version 3.1.141; davor greift die Fallback-Höhe). Dunkel: ?theme=hell aus der URL streichen.

<!-- Wulmstörper Tipprunde — aktuelle Rangliste (live, hell) -->
<div style="max-width:820px;margin:0 auto">
  <iframe class="wt-rangliste-iframe"
          src="https://tipp.wulmstorf.net/embed/podium?theme=hell"
          title="Aktuelle Rangliste – Wulmstörper Tipprunde"
          style="width:100%;height:520px;border:0;display:block"
          loading="lazy"></iframe>
</div>
<style>
  @media (max-width: 639px) {
    .wt-rangliste-iframe { height: 720px !important; }
  }
</style>
<script>
  /* Passt die iFrame-Hoehe automatisch an (das Widget meldet sich selbst). */
  window.addEventListener("message", function (e) {
    if (e.origin !== "https://tipp.wulmstorf.net") return;
    if (e.data && e.data.typ === "wt-embed-hoehe" && e.data.hoehe) {
      document.querySelectorAll(".wt-rangliste-iframe").forEach(function (f) {
        f.style.height = (e.data.hoehe + 6) + "px";
      });
    }
  });
</script>
